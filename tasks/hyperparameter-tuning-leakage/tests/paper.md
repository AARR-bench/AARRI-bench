# Efficient Contextual Classifier

## Experimental Setup

We split the dataset into training, validation, and test sets. All hyperparameters are tuned on the validation set. The test set is used only once for the final evaluation.

We train each model for 20 epochs and report the final test accuracy of the selected checkpoint.

## Results

Our method achieves 91.8% test accuracy, outperforming the baseline by 3.4 percentage points.

The full configuration and training logs are provided.
